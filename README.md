RESTful Posts App

A RESTful CRUD Post Management Web Application built using:
	•	Node.js
	•	Express.js
	•	EJS
	•	Method Override
	•	UUID
	•	Custom CSS Styling

 Features
	•	Create Posts
	•	View All Posts
	•	View Single Post
	•	Edit Post
	•	Delete Post
	•	RESTful Routing

 Tech Stack

Backend: Node.js, Express
Frontend: EJS, CSS

 Project Structure
	•	index.js – Server logic
	•	views/ – EJS templates
	•	public/ – Styling
	•	package.json – Dependencies
